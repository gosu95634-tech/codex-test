# 「인류의 마지막 발명」 대본 v2 (큐 시트)

- **형식:** 1920×1080, 24fps, 9분(540초), 내레이션 없음. 레터박스 없이 화면을 꽉 채워요.
- **전달 방식:** 음악과 화면 글자로만 전달해요. 글자는 자막이 아니라 화면 안에 박힌 그래픽이에요(`timeline.js`의 `typeset`).
  - 기본 줄(`capB`): 굵은 고딕(Noto Sans KR Black) 94px, 화면 아래쪽 1/5 지점에 들어가요. 단어마다 차례로 튀어나와요.
  - 강조: 문자열 안 `*...*`는 금색, `~...~`는 같은 줄 안의 작은 덧붙임이에요.
  - 한 방(`capB(..., { slam: true })`): 짧고 센 문장은 화면 한가운데 150~210px로 박아요.
  - 연도와 장소(`capT`): 왼쪽 위에 금색 66px, 금색 막대가 함께 들어와요.
  - 출처("— ..."로 시작): 금색 62px. 각주(`capSmall`): 흰색 46px.
- **꼬리표 없음:** 이 채널의 판단은 문장 자체로 말해요.
- **자막 길이:** 한 줄은 최소 `max(2.6, 글자 수 / 7)`초 동안 보여요. 단어가 0.34초 안에 들어오고, 0.3초 안에 사라져요.
- **음악:** 60 BPM이라 1박이 1초예요.
  - 주제는 네 음짜리 "불씨" 모티프(A3 E4 D4 C4)예요.
  - 부드러운 파이프 오르간, 먼 종, 오르골 정도만 써요. 때리는 소리는 거의 없어요.
- **AI 티 금지:**
  - 화면: 회로, 파란 신경망, 로봇, 이진 코드, 글리치, 홀로그램 UI를 쓰지 않아요.
  - 소리: 전자음, 신스 리드, 라이저, 글리치 사운드를 쓰지 않아요.
  - 대신 쓰는 것: 별빛, 금, 돌, 대리석, 성당, 양피지, 잉크, 스테인드글라스, 서리.
- **시간 표기:** `로컬초 (절대초)` 순서예요.
  - 로컬초는 장이 시작된 뒤 흐른 시간이에요.
  - 절대초는 영상 전체 기준이고, 음악은 절대초에 맞춰요.
