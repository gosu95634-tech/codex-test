# 「인류의 마지막 발명」 대본 v1

- **형식:** 1920×1080 · 24fps · 약 8분 27초 · 내레이션 없음
- **전달 방식:** 음악과 화면 글자로만 전달해요. 한 화면에 한 줄씩, 얇은 명조로 띄워요.
- **꼬리표:** `[판단]` `[예측]`은 화면 구석에 작은 "이 채널의 판단/예측" 꼬리표로 표시해요.
- **음악 기준:** 60 BPM, 1박 = 1초예요. 음악 주제는 네 음짜리 "불씨" 모티프예요.
- **AI 티 금지:** 전자음, 글리치, 회로, 파란 신경망, 로봇, 이진 코드를 쓰지 않아요. 별빛, 돌, 금, 성당, 경전 같은 이미지로 가요. 음악은 오르간, 종, 팀파니, 저음 드론 같은 어쿠스틱 계열만 써요. 신스 리드, 슈퍼소, EDM식 라이저는 쓰지 않아요.
