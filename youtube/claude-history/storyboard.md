# 「아모데이의 모험」 스토리보드 v1

- **형식:** 1920×1080 · 60fps · 1분 42초
- **음악:** 직접 합성하는 150 BPM 곡. 1마디는 1.6초이고 전체 64마디예요.
- **톤:** 까는 내용 없이 끝까지 하이프로 가요. Claude가 레벨업하는 성장 서사예요.
- **표시:** 대사는 전부 패러디예요. 시작할 때 "※ 이 영상은 패러디입니다"를 띄워요.

## 비주얼 방향
- **색:** 흑백 망가 톤을 기본으로 깔아요. 먹색, 종이색, 망점, 집중선이에요. 강조색은 오렌지 하나만 쓰고, 큰 타격 순간에는 화면 전체를 반전시켜요.
- **글꼴:**
  - 타이틀 카드: 가로로 눌린 극태 명조
  - 타격 글자: 블랙 고딕
  - ゴゴゴ 효과음: 일본 만화식 굵은 고딕
- **모션:** 비트마다 하드컷을 넣어요. 다운비트에는 2프레임 플래시나 반전, 화면 흔들림, 줌 펀치, 색수차, 망점 와이프, 파편 파티클을 써요.
- **캐릭터:**
  - 아모데이: 곱슬머리, 동그란 안경, 망가 잉크 스타일 캐리커처. 안경이 번쩍이는 연출을 넣어요.
  - Claude: 오렌지빛 코어로 표현해요. 공식 로고는 쓰지 않아요.
